# Assignment4-Stats-Scripts README
This README demonstrates how assignment four uses python for statistical analysis. This is done by using the instructions from SciPy lectures.

## GitHub
1. Begin by creating a new repository called Assignment4-Stats-Scripts on GitHub.
2. Ensure a .gitignore is created for __pycache__/, *.pyc, .ipynb_checkpoints/, .env/, .venv/, data/, and *.csv. Use vi .gitignore.
3. Clone repository with git clone to local machine.

## Environment Creation
1. Create a conda environment and name it stats-env.
2. Configure the channels to list bioconda, conda-forge, and defaults.
3. Initially include the dependencies python=3.10 and jupyterlab.
4. Use conda install in Jupyter to update the environment with numpy, scipy, matplotlib, pandas, statsmodels, and seaborn.
5. Move environment.yml to manual folder.
6. Create notebooks folder in manual.
7. In notebooks, create and save stats_python.ipynb.

## SciPy Lectures
1. Navigate to https://scipy-lectures.org/packages/statistics/index.html.
2. Download brain_size.csv and iris.csv. Create wages.txt using http://lib.stat.cmu.edu/datasets/CPS_85_Wages.
3. Go to Home Directory in Files on OSC. Move from the Assignment4-Stats-Scripts folder to the manual folder. Subsequently, go into the notebooks folder to upload the three files.
4. Return to the SciPy lectures URL and complete all sections, including exercises.
5. Use markdown cells for section titles and descriptions in the Jupyter notebook stats_python.ipynb.
6. Utilize comments in Python.
7. As the tutorial is being completed, ensure that code cells are being properly separated.
8. Complete all exercises in their own code cells as well.
9. Save the notebook upon completion and git commit.
